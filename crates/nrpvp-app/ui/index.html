    The night awaits.

    Your existing Seamless Co-op save is kept. If you have none, setup installs the bundled starter save for this Steam account.

    Your signed-in Steam account is detected automatically when you press Play.

    Start Steam, then press Play. The launcher closes itself once the game starts, so it does not take memory while you play.

    • Always start the game from this launcher (or nrpvp_launcher.exe), never with Steam's Play button.
    • In the Roundtable, pick the Battle Royale card (the last one), set Number of Players to Solo, and press Commence.
    • Everyone you play with needs the same version of the mod and of Seamless Co-op.
